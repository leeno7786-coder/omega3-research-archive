## Five Hard Laws

### Law 1 — Shared Lineage Budget

Each lineage owns one finite shared reflection pool.
All descendants consume from same budget.

```yaml
lineage:
  id: uuid
  max_budget: 12
  consumed: 0
```

Exhaustion requires terminal verdict.

---

### Law 2 — Resolution Class Separation

#### Operator Verified

External truth confirmation.

```yaml
resolution_class: operator_verified
reopenable: false
```

#### Provisional Internal

Internal coherence only.

```yaml
resolution_class: provisional_internal
reopenable: true
confidence: 0.0-1.0
```

Self-resolution can never overwrite operator truth.

---

### Law 3 — Refractory Escalation

```yaml

  cooldown_hours: 6
  decay_lambda: 0.2
```

Escalation pressure decays exponentially.
No monotonic amplification.

---

### Law 4 — Held Set Bound

```yaml
MAX_HELD_LINEAGES: 3
```

Eviction policy:

* Lowest salience removed
* Redundant ancestry collapsed

Operator receives only highest-value matured questions.

---

### Law 5 — DeepSleep Census

Every DeepSleep pass asserts:

```python

assert held_count <= MAX_HELD
assert no_budget_violation()
assert no_monotonic_priority_drift()
```
