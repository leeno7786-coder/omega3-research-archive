# PART I — CORE SCORING FORMULAS

## 1. `tension_score`

### Purpose

Measures cognitive pressure.

> "How badly does this need resolution?"

Tension is generated by contradiction + repetition + uncertainty + blockage.

### Formula

```
tension_score =
(
  contradiction_weight
+ repeated_failure_weight
+ uncertainty_weight
+ blocked_execution_weight
+ identity_risk_weight
) / 5
```

Normalized:

* 0.00 → no tension
* 1.00 → critical tension

### Components

**`contradiction_weight`**

* conflicting memories
* policy mismatch
* conflicting conclusions
* none = 0.0
* weak = 0.4
* strong = 0.8
* critical = 1.0

**`repeated_failure_weight`**

```
min(failure_count / threshold, 1.0)
```

Example:

3 failures threshold

* 1 failure = 0.33
* 3 failures = 1.0

**`uncertainty_weight`**

Based on Meta confidence inversion

```
uncertainty_weight = 1.0 - confidence_score
```

**`blocked_execution_weight`**

Can the system proceed?

* no block = 0.0
* minor block = 0.4
* major block = 0.8
* hard stop = 1.0

**`identity_risk_weight`**

Omega layer result

* none = 0.0
* minor = 0.3
* moderate = 0.6
* severe = 1.0

## 2. `resolution_value`

### Purpose

> "How valuable is solving this?"

Not urgency.

Importance.

### Formula

```
resolution_value =
(
  strategic_value
+ recurrence_value
+ capability_gain
+ identity_stability_value
+ operator_relevance
) / 5
```

### Components

**`strategic_value`**

From Global layer

> "How much does this affect long-term trajectory?"

**`recurrence_value`**

How often it returns

```
min(repeat_count / threshold, 1.0)
```

**`capability_gain`**

Would solving this permanently improve Omega?

* minor = 0.2
* useful = 0.5
* major = 0.8
* foundational = 1.0

**`identity_stability_value`**

Does resolution preserve coherence?

**`operator_relevance`**

Would the operator care if unresolved?

---

## 3. `persistence_score`

### Purpose

> "How long has this remained unresolved?"

Curiosity must punish neglect.

### Formula

```
persistence_score =
(
  cycle_reappearance
+ unresolved_duration
+ repeated_reopen_rate
) / 3
```

### Components

**`cycle_reappearance`**

```
min(appearances / threshold, 1.0)
```

**`unresolved_duration`**

Time-based

```
hours unresolved / threshold
```

capped at 1.0

**`repeated_reopen_rate`**

Was it "solved" but keeps returning?

High value = structural issue

---

## 4. `capability_compounding_score`

### Purpose

Global Layer asks:

> "If solved, does this permanently make Omega better?"

This is critical.

This separates patching from evolution.

### Formula

```
capability_compounding_score =
(
  permanent_gain
+ cross_domain_impact
+ automation_value
+ future_failure_reduction
+ infrastructure_value
) / 5
```

### Components

**`permanent_gain`**

Temporary fix vs structural upgrade

**`cross_domain_impact`**

Does it help one task or many?

**`automation_value`**

Removes repeated operator/manual work?

**`future_failure_reduction`**

Reduces recurrence probability

**`infrastructure_value`**

Improves architecture itself

(memory, guardian, schemas, retrieval, etc.)

These score highest.

# PART II — FAILURE FLOW LAW

## Rule: ALL 13 LAYERS ALWAYS EXECUTE

Even if there is "nothing to do."

No short-circuit cognition.

Because absence is information.

### Why

If Memory returns nothing:

that itself is a cognitive event.

If Meta has low confidence:

that itself is a decision.

If Curiosity declines pursuit:

that itself must be justified.

No invisible null states.

Only explicit states.

---

### Example — Memory returns zero matches

**BAD:**

skip rest of stack

**GOOD:**

```json
{
  "memory_gap_detected": true,
  "fallback_mode": "zero_memory"
}
```

Then continue.

* Curiosity may trigger.
* Development may detect retrieval weakness.
* Guardian may classify write posture.
* DeepSleep may strengthen gap patterns.

Nothing gets skipped.

---

### Example — Meta confidence low

**BAD:**

model unsure, continue anyway

**GOOD:**

```json
{
  "confidence_score": 0.22,
  "verification_required": true,
  "recommended_next_action": "ask"
}
```

Then continue.

* Global evaluates significance.
* Omega checks identity implications.
* Guardian verifies boundaries.

---

### Example — Curiosity says `should_pursue = false`

**BAD:**

nothing happens

**GOOD:**

```json
{
  "should_pursue": false,
  "ignore_reason": "low value + high cost"
}
```

Persist it.

Because non-pursuit is still a decision.
