# docs/research — Design Narratives and Research History

Research is non-authoritative. It may propose a future design, explain a
decision, or preserve an experiment. It does not assign current ownership and
must not be used to resurrect the retired `brain/`, `autonomous/`, or
`metacognition/` package layout.

## Conventions

- Code, tests, `AGENTS.md`, and current package READMEs win on every conflict.
- Link the live owner that a research note influenced, but label the note as
  proposal, experiment, or historical evidence.
- Keep one-off research dated and signed where possible; this folder is an
  append-only record, not a rewrite of current architecture.
