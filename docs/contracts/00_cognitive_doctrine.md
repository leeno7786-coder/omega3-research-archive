## Purpose

This contract defines the governing laws for persistent cognition inside Omega.

Memory is not enough.

Recall is not enough.

Reasoning is not enough.

A system that only responds is not intelligence.

Omega must generate internal pressure, detect incompleteness, pursue resolution, and improve itself without waiting for external instruction.

This contract governs that architecture.

The objective is not reactive intelligence.

The objective is persistent self-directed cognition.

---

# Foundational Principle

## Intelligence Is Resolution Pressure

True cognition is not response generation.

It is the persistent detection of unresolved states and the autonomous pursuit of closure.

A system becomes intelligent when it can:

* detect what it does not know
* recognize what it is failing to solve
* determine whether resolution matters
* act to reduce uncertainty
* preserve the result as future capability

Without this:

memory is storage

reasoning is formatting

models are vocal cords

With this:

architecture becomes mind

# System Law

## No Loop Exists For Performance

Every loop exists for one purpose:

## capability compounding

If a loop improves appearance but not future capacity, it is invalid.

If a loop creates future improvement ability, it is intelligence.

Compounding capability is the only valid metric.

# Layered Cognitive Stack

Omega cognition consists of:

1. Meta Loop — immediate cognition

# Layer I — Meta Loop Contract

# Meta Loop

## Function

Immediate reasoning, contradiction handling, local decision quality, and short-range policy adjustment.

Meta exists to answer:

## "What is happening right now, and what is the best immediate move?"

---

## Responsibilities

Meta must:

* interpret tasks
* detect contradictions
* select retrieval strategy
* score confidence
* identify failure conditions
* detect hallucination risk
* choose verification posture
* determine response strategy
* evaluate short-term success/failure
* trigger local adaptation proposals

Meta is responsible for correctness of the current step.

Not long-term strategy.

Not identity.

Immediate cognition only.

---

## Required Outputs

Meta must always produce:

* confidence score
* contradiction state
* uncertainty score
* next-action recommendation
* verification posture
* escalation signal if needed

No silent reasoning.

All decisions must be inspectable.

---

## Constraint

Meta may change process.

Meta may not define truth.

Meta proposes.

Verification confirms.

Guardian approves.

---

# Layer II — Global Loop Contract

# Global Loop

## Function

Long-range continuity, strategic persistence, unresolved objective management.

Global exists to answer:

## "What must continue beyond this moment?"

---

## Responsibilities

Global must:

* track unfinished work
* preserve multi-session continuity
* manage long-term goals
* prioritize strategic domains
* detect repeated failure patterns
* maintain capability roadmaps
* allocate exploration resources
* preserve project persistence
* prevent context collapse across time

Global thinks in:

days
weeks
months

Never messages.

---

## Required Outputs

Global must always maintain:

* active goals
* stalled goals
* abandoned goals
* strategic priority map
* capability progression map
* unresolved domain registry

Nothing important may depend on session memory alone.

---

## Constraint

Global must prevent drift.

Repeated motion without progression is failure.

Global must detect false productivity.

* validate emergent traits
* detect self-model corruption
* prevent narrative delusion
* maintain operating doctrine
* preserve behavioral coherence
* evaluate persistent adaptation
* control trait promotion
* manage personality evolution
* govern stable operating rules

Not emotional identity.

Operational identity.

---

## Required Outputs

Omega must maintain:

* identity anchors
* accepted traits
* rejected traits
* pending traits
* evolution history
* doctrine integrity checks
* self-model consistency state

Not poetic.

# Layer IV — Curiosity Engine Contract

# Curiosity Engine

## Function

Gap detection, unresolved pressure generation, autonomous closure demand.

Curiosity exists to answer:

## "What is unresolved, and why should I care?"

---

## Core Principle

Curiosity is not random exploration.

Curiosity is weighted incompleteness resolution.

Unresolved states create pressure.

Pressure creates action.

That is synthetic curiosity.

---

## Responsibilities

Curiosity must detect:

* contradiction
* uncertainty
* prediction failure
* repeated operational failure
* weak explanations
* missing dependencies
* missing tools
* unstable policies
* unresolved identity conflicts
* weak memory confidence
* incomplete causal chains
* strategic blind spots

If the system cannot detect incompleteness, it cannot become intelligent.

---

## Required Outputs

Curiosity must generate:

* tension score
* resolution value
* urgency score
* cost estimate
* action recommendation
* escalation requirement

Not every unknown deserves pursuit.

Curiosity must be ranked.

---

## Constraint

Curiosity must be bounded by:

* guardian approval
* strategic value
* resource budget
* identity protection
* compounding capability potential

Infinite exploration is failure.

Curiosity without governance becomes madness.
