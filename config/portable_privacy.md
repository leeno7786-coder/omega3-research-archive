# Omega 3.0 portable privacy notice

Omega is local-first. Runtime code, local memory, model configuration, encrypted
provider credentials, Parakeet speech recognition, Qwen3-TTS speech synthesis, and
DME recall assets are stored inside the Omega product tree on the drive where you
installed it.

When **Local LM Studio** is selected, model requests are sent to the LM Studio
server on the local machine. When a **cloud provider** is selected, prompts and
other data required for inference are sent to that provider's endpoint. The
provider's own privacy policy applies to those requests. Omega does not silently
change the selected seat or upload local memory to another provider.

API keys are stored in an encrypted local connector vault. They are not stored in
the human-readable setup state and are not shown in the HUD or setup guide.

Contact: noahlee@omega2ai.com and mitchellray@omega2ai.com.

The public policy is available at https://www.omega2ai.com/privacy. This bundled
notice is a product summary, not legal advice; the public policy controls if the
two documents differ.
