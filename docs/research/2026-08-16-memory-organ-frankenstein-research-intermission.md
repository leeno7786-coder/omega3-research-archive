## 1. Purpose

After Cuts 1–4, stop implementation and deliberately search outside the current design for mechanisms that could improve the final memory organ before later cuts harden assumptions around graph topology, DME semantics, association learning, and projection geometry.

This memo is not an implementation plan. It does not authorize Cut 5A, modify the decision register, or resolve any open RQ.

The objective is to answer:

> **Given the architecture already proven through Cut 4, what mechanisms from neuroscience, sparse associative memory, hyperdimensional computing, cognitive maps, and plasticity theory can be combined to make DME a stronger embedding-free associative memory organ without weakening filesystem sovereignty or RecallVerifier authority?**

The intended next step is independent critique by Fable 5, followed by operator/reviewer reconciliation before any idea becomes an RQ, ADR, or cut requirement.

---

## 2. Frozen ground truth this research must respect

Nothing proposed here may violate these already-ratified laws:

1. **Canonical filesystem is truth.** Graph, DME, registries, planes, manifests, and NPU artifacts are projections.
2. **Candidate is not authority.** RecallVerifier remains the only final admission authority.
3. **CUE != CLAIM.** Language-generated or derived routing features can retrieve; they cannot prove factual truth.
4. **Stable coordinates, plastic connectivity.** Learning changes accessibility/association, not canonical address identity.
5. **No learned dense embedding dependency in the final organ.**
6. **Runtime recall is read-only.** Durable adaptive mutation belongs to DeepSleep.
7. **Exact execution attribution is required for durable association credit.** Plausible graph routes do not train the organ.
8. **Full rebuild remains the correctness oracle.**
9. **Hardware accelerates semantics; hardware does not define semantics.** CPU/reference and IRON/XDNA must remain exact.
10. **Projection lag is legal; silent projection loss is not.**

Cut 4 additionally froze the producer-side separation:

```text
canonical durability != projection freshness
```

This research therefore focuses on the **projection / associative substrate**, not on changing what counts as truth.

## 4. Research synthesis — the strongest architectural correspondences

### 4.1 Hippocampal indexing suggests DME should be an index, not the memory

Hippocampal indexing theory describes a fast index capable of reactivating distributed cortical content from partial cues. Computational hippocampal models further separate sparse pattern separation from associative completion and downstream reinstatement.

Omega already has the stronger epistemic version of this separation:

```text
biology / theory              Omega
---------------------------   -------------------------------
distributed cortical trace    canonical filesystem record
hippocampal index             DME seat / sparse address state
partial cue                   RecallPlan / CueReceipt
pattern completion            direct / structural / learned DME activation
reinstatement                 canonical record recovery
truth/admission               RecallVerifier (Omega-specific)
```

**Research consequence:** DME should be optimized for *finding and reinstating canonical memories*, not for becoming a second truth store.

**Important implication for DISC-MO-003:** raw `memory_id` probably belongs to locator/index identity, not ordinary semantic cue vocabulary. The current ID-shape sanitizer is an interim shield, not a satisfying final semantic boundary.

### 4.2 Dentate-gyrus / Kenyon-cell pattern separation suggests a derived sparse expansion layer

Both hippocampal pattern-separation models and the Drosophila mushroom body use a recurring motif:

```text
compact / overlapping inputs
          ↓
expansion into a larger representational field
          ↓
competition / thresholding / sparsification
          ↓
more separable sparse patterns
```

For Omega, the raw material need not be pixels or neural activity. It can be already-lawful symbolic addresses:

```text
resolved query addresses
+ role/source class
+ lobe/context policy
        ↓
deterministic combinatorial projection
        ↓
sparse derived feature field
        ↓
fixed sparsity / WTA threshold
        ↓
DME associative scoring
```

Crucially, these derived bits would **not** be new CoordinateRegistry semantic identities and would never count as factual proof. They would be generation-versioned projection features computed from existing lawful inputs.

A candidate feature family could include deterministic conjunctions such as:

```text
bind(address_A, address_B)
bind(entity_address, relation_role)
bind(address, temporal_role)
bind(address_A, address_B, context_class)
```

The research question is not whether arbitrary hashing can create many bits. It can. The question is whether a **bounded sparse expansion** creates useful overlap geometry for paraphrase/association while reducing destructive collisions and hub activation.

Candidate design constraints:

- no query-time CoordinateRegistry minting;
- fixed/versioned seed and projection algorithm;
- deterministic CPU reference;
- exact NPU parity later;
- fixed maximum expansion density;
- source address provenance retained for attribution;
- derived features cannot independently satisfy RecallVerifier source proof;
- full projection rebuild regenerates identical derived features.

This idea is more compatible with Omega than replacing current DME rows with generic 8K/16K hypervectors, because it can be layered on the existing 262,144-bit DME geometry and tested without changing canonical address identity.

### 4.3 Sparse binary compositional binding may provide structure-sensitive similarity without dense embeddings

Work on sparse binary distributed representations shows that complex structures can be bound into fixed-dimensional sparse codes while preserving useful overlap with related structures and, in some schemes, with their components.

That suggests a specific direction for Omega: derive sparse projection features from **role-filler structure**, not from raw text similarity.

Example conceptual distinction:

```text
plain terms:
  Noah, project, Omega

role-aware structure:
  PERSON:Noah
  OWNS/BUILDS:Omega
  ROLE:project

bound projection features:
  bind(PERSON, Noah)
  bind(BUILDS, Omega)
  bind(Noah, BUILDS, Omega)
```

This would give two records overlap because they share auditable symbolic structure, not because a learned encoder placed their sentences near one another.

Potential value:

- paraphrase robustness through shared normalized roles;
- order/relation sensitivity;
- less dependence on exact lexical token overlap;
- direct compatibility with bitwise overlap scoring;
- contributor identities can remain reconstructible if binding provenance is explicit.

### 4.4 CA3 / Willshaw-style completion is a serious alternative to learned OR planes

Current DME hop planes are excellent for fast reachability but have a known information-loss property:

```text
OR(neighbor rows) -> candidate reachability
                 -> contributor identity erased
```

That is acceptable for candidate discovery and diagnostic structural hops, but it creates a future exact-credit problem for learned associations.

Sparse binary associative memories such as Willshaw-style networks suggest another primitive:

```text
sparse active cue features
          ↓
binary hetero/auto-associative matrix
          ↓
thresholded output activation
          ↓
optional bounded second/third completion step
```

Research hypothesis: a sparse associative crossbar could preserve enough source-column / association identity to make winner attribution mechanically provable while still mapping well to binary matrix hardware.

This should not replace current OR planes by assumption. It should be compared against them experimentally before Cut 9 freezes learned-plane semantics.

Candidate comparison dimensions:

```text
                           Tiered OR planes     Sparse associative matrix
candidate reach            strong               to measure
binary hardware fit        strong               strong
storage simplicity         strong               moderate
exact contributor proof    weak / second pass   potentially strong
iterative completion       awkward              native
fanout explosion           bounded by planes    threshold-dependent
full rebuildability        strong               strong if deterministic
plastic update locality    plane/tier update    edge/weight update
```

Questions that must be measured:

- Does bounded iterative completion materially improve zero-overlap or multi-hop retrieval?
- How many iterations before false attractors/hubs dominate?
- Can winner-only attribution identify the actual contributing associations exactly?
- What is the capacity/density envelope under realistic Omega codes rather than optimal random sparse codes?
- Can the representation remain efficient on current IRON/XDNA hardware geometry?

No production learned-association topology should be chosen from theory alone.

### 4.5 Clone-structured cognitive graphs suggest projection-only context states

A recurring memory problem is **aliasing**: the same observation/entity/token can participate in different latent contexts.

Examples:

```text
Apple -> company | fruit
bank  -> finance | river
Noah  -> Omega engineering | REACT proposal | hardware test | family context
```

Clone-structured cognitive graph work separates the same observation into context-specific hidden states learned from sequential/relational structure.

Omega should not clone canonical truth. A compatible variant would be **projection-only context states**:

```text
canonical entity / memory
        |
        +--> context-state A
        +--> context-state B
        +--> context-state C
```

Properties if ever explored:

- clones are derivative and disposable;
- each clone points back to canonical evidence;
- context state cannot create new factual content;
- state identity must be deterministic/rebuildable or belong to a clearly adaptive sidecar;
- RecallVerifier still verifies canonical records, never clone state as truth.

This is potentially powerful, but it is **not proposed for Cut 5A**. It is a later research branch because it introduces hidden-state inference and could substantially change projection topology.

### 4.6 Predictive cognitive maps suggest a separate directed “what follows” memory surface

Successor-representation / predictive-map work models memory not only as static adjacency but as expected future occupancy under experience.

Omega already has natural candidate relation families:

```text
PREDICTS
TEMPORALLY_LINKED
USED_TOGETHER
SAME_GOAL
```

A later predictive projection could encode directed experiential transitions:

```text
state/event/tool A
   ├──> likely next state B
   ├──> likely next state C
   └──> likely tool/action D
```

Possible multi-horizon form:

```text
NEXT    short horizon
SOON    intermediate horizon
LATER   broad horizon
```

This is materially different from structural graph truth. It would be an experience-conditioned navigation surface: **what Omega should expect to encounter next**, not what canonical evidence says is factually related.

If built, it belongs to learned association/planning research after exact eligibility and credit are proven.

### 4.7 Three-factor plasticity strongly supports making eligibility a first-class state

The three-factor literature separates local activity from later reinforcement by using an eligibility trace that exists before reward/punishment/novelty arrives.

Omega's current architecture is already close, but this suggests a sharper state machine:

```text
ACTIVATED
   ↓
EXECUTION CONTRIBUTION PROVEN
   ↓
ELIGIBLE
   ↓
OUTCOME / RPE ARRIVES
   ↓
CREDIT ASSIGNED
   ↓
DEEPSLEEP DURABLE STRENGTH CHANGE
```

Research consequence: do not collapse these into one `activation_strength` scalar.

Potential future eligibility record dimensions:

- exact episode id;
- exact projection generation;
- exact association/contributor id;
- activation magnitude or matched-bit contribution;
- candidate/verifier result;
- whether evidence entered cognition/action;
- eligibility age/decay;
- capture status (uncaptured | positive | negative | expired).

This would make learning causality auditable and naturally limits delayed credit through eligibility decay rather than arbitrary episode-wide reward spraying.

### 4.8 Forgetting should primarily alter accessibility, not truth

Active-forgetting and consolidation research reinforces the separation already present in Omega:

```text
canonical fact / episode       durable truth
structural graph relation      evidence-derived topology
engram accessibility           StrengthIndex
learned association access     AssociationStrengthIndex / learned projection
```

Plasticity should therefore be allowed to make a pathway:

```text
strong -> medium -> weak -> dormant -> retired-from-active-projection
```

without deleting the canonical memory that originally participated.

A further research idea is **homeostatic association budgeting**. Instead of independent edges all saturating toward maximum strength, each source memory/context may have a bounded outgoing excitability budget.

Conceptual example:

```text
A -> B  0.70
A -> C  0.20
A -> D  0.10
```

New reinforcement redistributes a bounded resource or triggers compensatory scaling rather than allowing `A -> everything = 1.0`.

This could suppress runaway hubs, path monopoly, and saturation while making learned connectivity competitive and sparse. It must be tested, not assumed.

### 4.9 Complementary learning systems reinforce the fast-index / slow-integration split

Complementary-learning-system theory separates rapid storage of specific episodes from slower integration of structure across experience to avoid interference.

An Omega-compatible mapping is not a literal hippocampus/neocortex copy. A useful abstraction is:

```text
FAST / SPECIFIC
canonical episode write + stable DME indexing

SLOWER / INTEGRATIVE
DeepSleep replay + structural support + learned associations + pruning/homeostasis
```

The key design lesson is **do not force immediate global semantic integration on every new memory**.

Cut 4 already moved Omega in this direction:

```text
canonical commit now
projection catches up later
adaptive integration at DeepSleep
```

This supports preserving a fast, precise write/index path while allowing learned relational structure to mature gradually and reversibly.

It also argues against shipping a prelearned personal association cortex: learned connectivity should emerge from lived, verified experience.

## 5. Candidate Frankenstein architecture — research sketch only

The strongest combined hypothesis is not “replace DME with HDC” and not “copy the hippocampus.” It is to preserve DME and add carefully bounded sparse operations around it:

```text
Natural-language query
        ↓
RecallPlan + bounded symbolic cues
        ↓
existing CoordinateRegistry lookup (NO mint)
        ↓
[optional research layer]
DG / Kenyon-like deterministic sparse expansion
  - role-aware conjunctions
  - fixed/versioned projection seed
  - fixed sparsity budget
        ↓
DME sparse activation
  - direct rows
  - structural topology
  - optional sparse associative completion
        ↓
execution-bound attribution / RecallBasis
        ↓
canonical filesystem reinstatement
        ↓
RecallVerifier
        ↓
cognition/action
        ↓
exact eligibility tags
        ↓
closed episode outcome / RPE
        ↓
DeepSleep plasticity + forgetting/homeostasis
```

Possible later branches, intentionally outside the immediate sketch:

```text
projection-only context clones
predictive / successor-like transition planes
multi-horizon temporal expectation
hierarchical context/state abstraction
```

These are potentially powerful, but they introduce hidden-state and planning semantics and should not contaminate the first experiment with sparse expansion/completion.

### Leading hypothesis — not a decision

The most promising near-term research direction is:

> **Keep Cut 5A structural-only, but before Cuts 6–9 freeze the learned-association mechanism, compare the current tiered OR-plane concept against a deterministic sparse-expansion + sparse-associative-completion design with exact contributor attribution.**

Why this branch first:

- it directly targets embedding-free semantic reach;
- it attacks the known OR-plane attribution weakness;
- it matches DME's binary geometry and IRON/XDNA strengths;
- it can remain projection-only and rebuildable;
- it does not require changing canonical truth or RecallVerifier;
- it can be evaluated independently before production integration.

## 6. What this research explicitly does **not** recommend

### 6.1 Do not make a hypervector the primary key or truth authority

The prior HDC concept note suggests treating the hypervector as a primary key. That conflicts with the frozen Omega hierarchy. A derived representation may locate candidates; canonical identity and source proof remain separate.

### 6.2 Do not equate graph reachability with truth

Bit-exact reachability proves only that the stored topology permits a route. It does not prove that the terminal record answers the user's question or is factually valid. RecallVerifier remains mandatory.

### 6.3 Do not claim collision-free semantics from dimension alone

High-dimensional random codes have useful concentration properties, but semantic collision/noise depends on code construction, density, binding, corpus load, thresholds, and structured inputs. Measure the real operating envelope.

### 6.4 Do not replace one opaque semantic model with opaque random geometry

Derived sparse features must remain reconstructible from lawful symbolic inputs and versioned rules. Random projection is acceptable only when the seed/rule is deterministic and its provenance is auditable.

### 6.5 Do not add unbounded recurrent completion

Associative completion must be bounded. No uncontrolled attractor wandering, recursive hallucination, or unlimited spreading activation.

### 6.6 Do not let biological plausibility overrule Omega's epistemic safeguards

Brains misremember. Omega can borrow pattern separation, completion, eligibility, replay, and forgetting without copying confabulation as a feature.

## 7. Proposed research experiments before any new ADR

These are **research harnesses**, not production cuts.

### EXP-R01 — semantic address namespace versus locator namespace

Compare current seating with a prototype that removes raw `memory_id` from semantic feature registration while preserving canonical locator mapping.

Measure:

- direct recall parity;
- generated-cue attack surface;
- registry vocabulary pressure;
- rebuild determinism;
- zero-overlap retrieval impact.

### EXP-R02 — deterministic sparse expansion

Input only lawful query/record addresses and normalized roles. Produce a larger sparse derived bit field using fixed seed/rules.

Sweep:

```text
expansion ratio
active-bit percentage
conjunction order (1/2/3)
WTA / threshold policy
role-aware vs role-blind projection
```

Measure:

- verified recall@K;
- false activation / hub rate;
- overlap distribution between related/unrelated memories;
- query density;
- bit-popcount cost;
- provenance/attribution recoverability;
- exact CPU determinism.

### EXP-R03 — tiered OR planes versus sparse associative completion

Build both from the same fixed corpus / same association graph.

Compare:

```text
candidate recall
verified precision
zero-overlap recall
multi-hop recall
winner attribution coverage
ambiguous contributor rate
iterations to convergence
false attractors
memory footprint
CPU latency
projected IRON/XDNA operation count
```

Bound associative completion to a small fixed iteration count; no production enablement.

### EXP-R04 — role-aware binding / thinning

Compare plain symbolic-address overlap against bounded role-filler binding features.

Attack with:

- paraphrases preserving roles;
- inverse relations;
- same words / different relation;
- same entity / different context;
- negation;
- distractor conjunctions.

Goal: determine whether sparse compositional binding adds semantic reach without creating un-auditable pseudo-meaning.

### EXP-R05 — eligibility lifecycle

Prototype an ephemeral, non-durable eligibility state using exact execution attribution.

Measure alternative decay/capture rules for:

```text
activation -> eligibility -> positive/negative capture -> expiry
```

No durable association mutation is required for this experiment. The purpose is to establish whether causal credit can be represented cleanly before Cut 7.

### EXP-R06 — homeostatic association budget

On synthetic learned hubs, compare independent edge saturation against bounded per-source normalization/budgeting. Measure useful recall, path monopoly, churn, reversal/unlearning speed, and false hub activation.

## 13. External counterproposal — Gemini HQ-NP semantic-to-binary bridge

**Source:** Gemini response supplied by the operator after reviewing the earlier model-free HDC/bit-graph concept note.
**Status:** external research input only; not Fable's review; not an ADR; not a Cut-5A plan amendment.

Gemini proposes a four-part bridge:

1. a tiny frozen neural semantic encoder producing a low-dimensional dense latent `z`;
2. a fixed sign-random-hyperplane projection `h = sign(Phi z)` into a large binary code;
3. VSA role/filler binding over those binary codes;
4. an associative cleanup layer plus compressed sparse graph storage.

The proposal attacks a real weakness in purely lexical or token-hash HDC: deterministic hashing preserves identity and compositional form, but does not create semantic proximity between unrelated lexical forms such as `heart attack` and `acute myocardial infarction` unless that relation is supplied elsewhere.
### 13.1 Part A — sign-random-hyperplane projection

This mathematical core is legitimate and worth measuring. Sign-random-projection LSH provides an unbiased estimator of angular similarity; later variants such as Super-Bit reduce estimator variance at a fixed bit budget.

For normalized dense inputs `z1, z2`, independent random hyperplanes satisfy:

```text
Pr[sign(r·z1) != sign(r·z2)] = angle(z1,z2) / pi
```

so a sufficiently long binary sketch estimates angular/cosine neighborhood with Hamming distance.

However, Gemini's numerical example must be corrected before it is used as evidence. If cosine similarity is `0.92`, then:

```text
angle = arccos(0.92) ≈ 0.403 rad
expected normalized Hamming ≈ 0.403 / pi ≈ 0.128
```

not `0.08`. A Hamming fraction near `0.08` corresponds to cosine similarity near `cos(0.08*pi) ≈ 0.969`.

**Research disposition:** SUPPORT AS AN EXPERIMENTAL TRANSFORM, not yet as a production semantic source.
### 13.2 Part B — mandatory frozen neural encoder conflicts with the frozen end-state

Gemini's proposed runtime chain is:

```text
natural language -> tiny learned encoder -> dense latent -> binary projection
```

If that encoder is required for memory write, indexing, projection, or recall, it directly conflicts with ADR-MO-008 and the embedding-obsolete definition in `17`: the final memory organ may not require a learned dense embedding model for memory operation.

The random hyperplane transform does not remove that dependency; it quantizes the learned encoder's geometry. Semantic authority still originates in learned dense latent space.

This does **not** make HQ-NP useless. It gives us three legitimate research uses:

- **teacher/comparator:** quantify how much semantic neighborhood the non-neural DME route is missing;
- **offline experimental oracle:** produce target neighborhoods during R&D without becoming production authority;
- **ablation:** compare lexical-symbolic, sparse-expansion, and neural-to-binary inputs using the same downstream binary scorer.

A production variant would need a non-neural source for the semantic atoms or a separate operator ruling that changes ADR-MO-008. No such ruling is made here.

**Research disposition:** REJECT AS MANDATORY FINAL MEMORY FRONT-END; SUPPORT AS RESEARCH COMPARATOR/TEACHER.
### 13.3 Part C — VSA role/filler binding aligns strongly with the research memo

Gemini's subject / relation / object role binding is directionally compatible with EXP-R04. The valuable idea is not the exact XOR-plus-majority formula by itself; it is the separation of:

```text
semantic atom identity
from
structural role identity
```

so `A treats B` does not collapse into the same representation as `B treats A`.

Sparse VSA literature also supports testing role/filler binding in sparse or block-sparse representations rather than assuming dense bipolar hypervectors are mandatory.

Requirements for any Omega variant remain:

- binding must be deterministic and projection-versioned;
- derived role bits are routing features, not canonical claims;
- relation direction/type must remain recoverable for proof;
- bundling must not erase exact contributor attribution needed by ADR-MO-016;
- the same canonical state must regenerate identical projection state.

**Research disposition:** SUPPORT WITH MODIFICATION — test sparse/block-sparse role binding against the existing structural graph, not as a replacement for typed canonical relations.
### 13.4 Part D — the proposed Modern Hopfield cleanup is not bit-exact as written

Gemini's cleanup equation uses continuous inner products plus `softmax(beta * score)`. Modern Hopfield networks are explicitly continuous-state associative memories whose update rule is equivalent to attention. That is useful research, but it is not the same thing as a 1-bit XNOR/popcount cleanup primitive.

Therefore the claim that the displayed softmax cleanup remains `100% bitwise` or converges in `1–2 NPU cycles` is not established by the equation itself.

For Omega, the closer candidates are:

```text
A. tiered structural/learned OR planes          # current plan
B. sparse Willshaw-style binary association     # research candidate
C. bounded thresholded binary autoassociation   # research candidate
D. continuous Modern Hopfield cleanup           # comparator only unless exact quantized semantics are separately proven
```

The cleanup experiment must measure candidate recovery, cross-talk, exact contributor attribution, capacity, and CPU/IRON parity. A cleanup layer may propose/recover a candidate address; it still cannot bypass RecallBasis or RecallVerifier.

**Research disposition:** SUPPORT THE CLEANUP FUNCTION; REJECT THE SOFTMAX IMPLEMENTATION AS THE ASSUMED BIT-EXACT PRODUCTION MECHANISM.
### 13.5 Part E — compressed sparse graph storage is compatible, but orthogonal to semantic meaning

Gemini is right to reject a naive dense `N x N` adjacency representation as the only storage format at scale. Omega already treats graph topology as sparse typed structure, and later NPU packing can use CSR/CSC/blocked sparse/bit-sliced forms as measured hardware layouts.

But sparse block storage solves a different problem:

```text
semantic representation problem != graph storage problem
```

Compressed sparse blocks can reduce memory traffic and improve locality without deciding what constitutes a semantic cue, association, proof, or learned edge.

This belongs primarily to the later projector/NPU program once reference semantics are frozen. Hardware storage format must remain derivative and bit-exact with the CPU/reference graph behavior per LAW-EO-008.

**Research disposition:** SUPPORT, DEFER IMPLEMENTATION TO HARDWARE/PROJECTOR DESIGN AFTER SEMANTICS FREEZE.
